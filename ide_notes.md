# Git в VS Code и в терминале

## Что удобно в VS Code

1. Панель Source Control показывает список изменённых файлов, поэтому перед коммитом удобно быстро проверить, что именно будет добавлено в историю.
2. Встроенный diff наглядно выделяет добавленные и удалённые строки и помогает проверить изменения до коммита.
3. Историю коммитов и состояние ветки можно посмотреть в одном окне, не переключаясь в терминал.

## Что удобнее делать в терминале

Сложные и точные операции с ветками удобнее выполнять в терминале: например, создавать ветку, просматривать все удалённые ветки, выполнять rebase или быстро проверять историю командой `git log --graph`.
