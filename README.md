# Практическая работа №2 — инфраструктура проекта

Учебный программный проект по дисциплине «Инструменты DevOps».

## Цель

Настроить инфраструктуру разработки: удалённый и локальный Git-репозитории, структуру исходного кода, документацию, тесты, GitHub Issues и GitHub Projects.

## Структура

- `src/` — исходный код;
- `tests/` — автоматические тесты;
- `docs/` — документация проекта;
- `pyproject.toml` — описание Python-проекта;
- `.gitignore` — исключения Git.

## Запуск

```bash
python3 -m src.devops_course
```

## Тестирование

```bash
python3 -m unittest discover -s tests -v
```
