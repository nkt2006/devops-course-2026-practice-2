# Мой пет-проект

## Идея

Telegram-бот для учёта учебных дедлайнов. Пользователь добавляет задания, указывает дату сдачи и получает напоминание перед дедлайном.

## Стек

Python, aiogram, SQLite.

## Цель

Научиться проектировать небольшое Python-приложение, работать с внешним API Telegram и применять GitHub Flow при разработке новых функций.

## Ближайшие шаги

1. Создать модель задания и локальное хранилище.
2. Добавить команды создания и просмотра дедлайнов.
3. Реализовать напоминания о приближающейся дате сдачи.
