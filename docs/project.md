# Документация проекта

## Назначение

Проект демонстрирует базовую инфраструктуру разработки: удалённый и локальный репозитории, историю изменений, документацию, задачи и доску проекта.

## Используемые инструменты

- Git — контроль версий;
- GitHub — удалённый репозиторий, задачи и проектная доска;
- Python — пример исходного кода;
- unittest — автоматическая проверка кода.

## Рабочий процесс

1. Работа планируется в GitHub Issues.
2. Состояние задач отслеживается на доске GitHub Projects.
3. Изменения фиксируются осмысленными коммитами.
4. Перед публикацией запускаются автоматические тесты.

## Базовые команды

```bash
git status
git add .
git commit -m "практика номер два"
git push origin main
```
